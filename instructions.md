# Linkwarden

Open the Linkwarden web interface from the StartOS dashboard to create the first account and begin saving links.

Use the `Configure Access` action to control future account registration. Use the `Configure SMTP` action to configure disabled, system, or custom outbound email delivery.

Linkwarden archives web content with Chromium and Playwright. For reliable archival and search, allocate enough memory for Linkwarden, PostgreSQL, Meilisearch, and the browser worker. A minimum of 4 GB RAM is recommended, with 8 GB preferred for active archiving.
